Methods & Tools

A shared guide for the lab. Pick a topic, read what each method is for, and jump to the right tool. Found something useful? Add it so everyone can find it.

Tip: hover over a tool name (or tap the i on a phone) to see what it is for.

How to add a method or tool

  1. Send the link to Nick, with the section it belongs to (DNA, RNA, Protein, Genomes, Tool collections, Learn, Figures).
  2. Add one sentence on what it does, and why you found it useful.
  3. It will then appear on this page.
